# Melissa Cloud APIs - OpenAPI Specifications

## Overview

This repository contains the [OpenAPI 3.0](https://swagger.io/docs/specification/v3_0/about/) specification files for [Melissa Cloud APIs](https://docs.melissa.com/cloud-api/cloud-api.html). They describe all the available endpoints for each API, as well as input parameters and responses.

## Getting Started

Check out our [Developer Portal](https://developer.melissa.com/) to view these specifications and try out all our Cloud APIs!

You may also host and view the OpenAPI pages on your local machine. Follow these steps to do so:

1. Make sure to have the latest version of [npm](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm) installed.
2. Clone this repository, then navigate into the `openapi` folder and run `npm install`.

```
git clone https://github.com/MelissaData/MelissaCloudAPI-OpenAPI-Specification
cd MelissaCloudAPI-OpenAPI-Specification/openapi
npm install
```

3. Run one of:

    a. `npm start` - The pages will be hosted on port `4000` by default.

    b. `npm start -- --port <PORT_NUMBER>` - Replace `<PORT_NUMBER>` with your desired port.

Note that you will need a [Melissa License Key](https://docs.melissa.com/melissa/license/license-information.html) to use our Cloud APIs.
